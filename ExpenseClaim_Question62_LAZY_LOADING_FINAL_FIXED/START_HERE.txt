EXPENSE CLAIM - QUESTION 62 - MANAGER APPROVAL FIX

1. Double-click RUN.bat
2. Wait for Tomcat to start on port 8080
3. Open http://localhost:8080/
4. Submit a claim.
5. In MANAGER QUEUE click Review.
6. Select the manager, enter remarks, and click Approve.
7. For a policy violation, choose: Yes - override policy violation.
8. The claim moves to FINANCE QUEUE.

FIXES IN THIS VERSION:
- Manager approval now handles stale browser queue rows safely.
- If a claim was already approved, the UI refreshes and tells you it is ready for Finance instead of showing a misleading error.
- Added POST approval endpoint in addition to PUT for compatibility.
- Manager decision modal pre-fills the remarks field with "Verified" so the demo can be approved immediately.
- Added JavaScript cache-busting so the browser loads the fixed approval logic.
- Policy amount display and live policy validation remain included.

IMPORTANT:
If you already ran an older version on port 8080, stop it first with Ctrl+C, then run this version.
